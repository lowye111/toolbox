# toolbox
my toolbox for yolo learner

## 工具箱介绍
这是一个实用的工具集合，包含多个可视化工具，帮助你快速完成各种任务。

## 启动方式
双击「启动工具.bat」打开工具菜单，点击相应按钮启动对应工具。
首次启动时会自动检测运行依赖，缺少时会提示一键安装。

### 卡片排序

工具多了以后可以按自己的习惯调整顺序：

- **点击**卡片 = 启动该工具（和以前一样）
- **长按**卡片约 0.35 秒进入拖动模式：卡片会被"拿起来"（描边变蓝、光标变抓手），
  并跟随鼠标移动；其它卡片平滑滑开让位，松手后自动归位并保存
- 顺序存在 `config.json` 的 `tool_order` 里，下次打开保持；
  想恢复默认顺序，把该项清空（`[]`）即可
- 拖动时把鼠标移到列表上下边缘会自动滚动（越靠边滚得越快）
- 新增的工具会自动排到末尾，卸载的工具会被忽略，不会打乱已有顺序

手感细节：长按等待期间若鼠标移动超过 6px 就取消长按、按普通点击处理，
避免"想点工具但手抖了一下"被误判成拖动。

## 环境要求

- Windows + Python 3.8 及以上（安装时勾选 “Add Python to PATH”）
- 基础依赖见 requirements.txt；菜单启动时会自动自检，缺失可一键安装
- 模型训练工具的训练功能额外需要：
  - conda 训练环境（默认名 `yolov5`，需已安装 ultralytics/torch），或使用装好 ultralytics 的系统 Python
  - 使用 yolov5 系列模型时需提供 yolov5 仓库目录（会自动在桌面、用户目录查找）

换电脑后若自动检测不到，可编辑根目录 `config.json`（首次运行自动生成，不纳入 git）：

| 配置项 | 说明 |
| --- | --- |
| conda_env | 训练环境名（默认 yolov5） |
| env_python | 直接指定训练环境的 python.exe 路径（优先级最高） |
| yolov5_dir | yolov5 仓库目录 |
| deepseek_api_key | 参数扫描工具「AI 识别」用的 DeepSeek API Key（可选，建议改用环境变量，见下） |
| deepseek_api_key_enc | 由工具自动生成的加密 Key（不要手填） |
| deepseek_model | AI 识别模型名，默认 deepseek-flash（可选 deepseek-v4-pro） |
| notes_dir | 参数扫描工具「说明」文件的保存目录（默认 toolbox/notes） |
| tool_order | 菜单卡片的排列顺序（长按拖动后自动写入，清空则恢复默认） |

## AI 识别：配置 API Key

「参数扫描工具」的 AI 识别需要一个 DeepSeek API Key。**最简单的方式是用界面填**：

打开「参数扫描工具」→ 点顶部 **🔑 API 设置** → 粘贴 Key → 点「保存」。
保存时会自动加密（见下），界面上只会显示打码后的 Key（如 `sk-620…803f`）。

窗口里还有两个实用功能：

- **测试连接**：直接向 DeepSeek 查询，立刻告诉你 Key 是否可用；
  失败时会带出服务端原因（例如 Key 已在后台被轮换/删除）。
- **模型名**：可选 `deepseek-flash` / `deepseek-v4-pro`，也可直接输入其它模型名。

如果还没配置 Key 就点「🤖 AI 识别」，工具会直接提示你打开这个设置窗口。

### Key 的存储方式（越靠前优先级越高）

1. **环境变量**：`setx DEEPSEEK_API_KEY "sk-你的Key"`（一次即可，Key 完全不落盘）
2. **界面保存 / config.json 密文**：用 Windows DPAPI 加密后存进 `deepseek_api_key_enc`。
   密钥由当前 Windows 账户托管，**密文拷到别的电脑/别的账户无法解密**，
   所以即使 config.json 被提交或分享也不会泄露。
3. **明文**：仅为兼容旧配置保留，读到时会自动迁移成密文。

> 注意：环境变量优先级最高——如果界面里保存了 Key 但仍提示无效，
> 先检查是否设置了 `DEEPSEEK_API_KEY` 环境变量（它会把界面配置覆盖掉）。
> 设置窗口顶部会显示当前 Key 的来源。

另外仓库内置了一个提交前检查（`tools/git-hooks/pre-commit`），会在 `git commit` 时扫描
**暂存区内容与提交信息**，发现疑似 Key 就直接阻断提交。新克隆的仓库需要装一次：

```powershell
python tools/install_hooks.py
```

（git 不会自动分发钩子，所以换机器要重新装。）

## 关于中文路径

Windows 下 `cv2.imread` / `cv2.imwrite` **不支持中文（非 ASCII）路径**：
前者静默返回 `None`，后者静默返回 `False`，很容易被误判成"处理失败"。
因此本项目统一通过根目录的 `img_io.py` 读写图片（内部走 `imdecode` / `imencode`），
数据集目录、视频路径、输出目录含中文都能正常工作。

## 工具列表

### 1️⃣ 参数扫描工具 (param_scanner_gui.py)

- 图标：⚙️
- 功能：批量查看、编辑、管理代码参数
- 特点：
  - 自动识别 .h/.hpp/.c/.cpp/.cc/.cxx 及 .yaml/.yml/.ini/.cfg/.conf/.ino 文件中的参数
  - 双栏管理：预调栏（置顶常用参数）+ 参数列表
  - 一键置顶、隐藏参数（顶部「显示隐藏项」可找回）
  - 支持单条/批量保存，保存前留 `.bak` 备份，按原编码与行尾写回；关闭时生成修改日志
  - 🤖 AI 识别（可选）：DeepSeek 过滤误报、生成用途说明、推荐置顶参数
    （点顶部「🔑 API 设置」即可在界面里填 Key 并测试连接，见上文）
  - 📝 手动说明：为参数添加备注，集中保存（默认 toolbox/notes，可用 config.json 的 notes_dir 指定），重开同一工作区自动加载

### 2️⃣ 文件批量重命名 (change_name.py)

- 图标：🔄
- 功能：批量重命名文件
- 特点：
  - 数字后缀修改：把纯数字文件名整体加减一个值（可限定数值范围）
  - 文件名修改：把非数字命名的文件改成连续编号
  - 支持原位改名或复制到新目录，执行前有预览与冲突提示

### 3️⃣ 视频抽帧工具 (frame_extract.py)

- 图标：🎬
- 功能：从视频中提取帧图片
- 特点：
  - 支持按帧数间隔、按时间间隔或指定帧号抽帧
  - 可查看视频信息
  - 输出到已存在的目录会先确认，避免误覆盖

### 4️⃣ 图片批量裁剪 (cut_gui.py)

- 图标：✂️
- 功能：对整目录图片用同一个区域批量裁剪
- 特点：
  - 鼠标在预览图上框选一次，自动换算回原图坐标
  - 批量应用同一裁剪区域，支持中文路径

### 5️⃣ 图片转RGB565 (img2rgb565_gui.py)

- 图标：🖼️
- 功能：将图片转换为 RGB565 格式的 C 数组头文件
- 特点：
  - 支持 PNG/JPG/BMP/GIF/WEBP 等常见图片格式
  - 可设置目标宽高（默认 128x128，适配 ST7735 128x160）
  - 等比缩放+黑边居中 或 拉伸填充两种方式
  - 自动生成 RGB565 数据（高字节在前）、宏定义与头文件保护宏
  - 预览原图与转换结果

### 6️⃣ 进度条标定尺 (ruler.py)

- 图标：📏
- 功能：透明进度条标定工具
- 特点：
  - 透明窗口，可叠加在其他界面上
  - 两个可拖动游标，记录位置与时间戳，用于判断进度条是否真的在走

### 7️⃣ 模型训练工具 (model_train.py)

- 图标：🤖
- 功能：训练机器学习模型
- 特点：
  - 自动检测 conda 训练环境（默认名 yolov5，可在 config.json 修改）
  - 自动查找 yolov5 仓库目录（可在 config.json 的 yolov5_dir 指定）
  - 支持 YOLOv5 / YOLOv8 / YOLO11 系列模型（v5 需 yolov5 仓库，v8/v11 需 ultralytics）
  - 训练页的「Python路径」即为实际执行训练的解释器（留空则用 PATH 中的 python）
  - 生成 data.yaml 时**按标签文件自动推断类别数**（取标签里最大类别 id + 1），
    不再写死 `nc`，避免换数据集后按错误类别静默训练
  - 训练/测试/导出/一键四处的输出读取统一走一个后台流程，训练期间界面不再冻结

## 注意事项

- 模型训练工具需要 YOLO 训练环境支持（自动检测，可用 config.json 指定）
- 点击「保存」才会真正写入文件；保存前会在同目录留一份 `.bak` 备份，并按原文件编码与行尾写回
- 参数扫描工具里被 `×` 隐藏的参数可通过顶部「显示隐藏项」找回
- 关闭工具菜单不会影响已启动的工具窗口
- 图片路径含中文时请勿改用 `cv2.imread/imwrite`，一律使用 `img_io`（见上）
- data.yaml 的 `nc` 会自动推断，但类别名仍是占位（rssn/wskg/…），
  换数据集时请按实际类别名修改 `names`（个数需与 `nc` 一致）
