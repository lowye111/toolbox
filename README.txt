工具箱介绍
这是一个实用的工具集合，包含多个可视化工具，帮助你快速完成各种任务。

启动方式
双击「启动工具.bat」打开工具菜单，点击相应按钮启动对应工具。

工具列表
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ 参数扫描工具 (param_scanner_gui.py)
   图标：⚙️
   功能：批量查看、编辑、管理代码参数
   特点：
   - 自动识别 .h/.hpp/.c/.cpp/.cc/.cxx 代码文件中的参数
   - 双栏管理：预调栏（置顶常用参数）+ 参数列表
   - 一键置顶、隐藏参数
   - 支持单条/批量保存，关闭时自动生成修改日志

2️⃣ 文件批量重命名 (change_name.py)
   图标：🔄
   功能：批量重命名文件，支持多种命名规则
   特点：
   - 支持多种命名模式
   - 批量处理，操作简便

3️⃣ 视频抽帧工具 (frame_extract.py)
   图标：🎬
   功能：从视频中提取帧图片
   特点：
   - 支持按时间间隔或指定帧号抽帧
   - 可查看视频信息

4️⃣ 图片转RGB565 (img2rgb565_gui.py)
   图标：🖼️
   功能：将图片转换为 RGB565 格式的 C 数组头文件
   特点：
   - 支持 PNG/JPG/BMP/GIF/WEBP 等常见图片格式
   - 可设置目标宽高（默认 128x128，适配 ST7735 128x160）
   - 等比缩放+黑边居中 或 拉伸填充两种方式
   - 自动生成 RGB565 数据、宏定义与头文件保护宏
   - 实时预览原图与转换结果

5️⃣ 进度条标定尺 (ruler.py)
   图标：📏
   功能：透明进度条标定工具
   特点：
   - 透明窗口，可叠加在其他界面上
   - 用于标定进度条位置

6️⃣ 模型训练工具 (model_train.py)
   图标：🤖
   功能：训练机器学习模型
   特点：
   - 自动激活 YOLO 环境（yolov5）
   - 适合训练 YOLO 系列模型

注意事项
• 模型训练工具需要 YOLO 环境支持（yolov5）
• 点击「保存」才会真正写入文件
• 关闭工具菜单不会影响已启动的工具窗口
